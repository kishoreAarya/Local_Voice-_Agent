# Local Voice-to-Voice AI Agent: Detailed System Design

## 1. System Components & Interfaces

### 1.1 Tool Execution Protocol
All tool calls generated by the LLM must strictly adhere to the following JSON schema envelope:

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "ToolCallEnvelope",
  "type": "object",
  "properties": {
    "tool": {
      "type": "string",
      "enum": [
        "get_weather",
        "whatsapp_message",
        "calendar_event",
        "chrome_browse",
        "file_manager"
      ]
    },
    "parameters": {
      "type": "object"
    }
  },
  "required": ["tool", "parameters"]
}
```

---

## 2. Parameter Schemas for Registered Tools

### Tool: `get_weather`
```json
{
  "location": "string (default: 'Hyderabad')"
}
```

### Tool: `whatsapp_message`
```json
{
  "phone": "string (E.164 format e.g., '+919876543210')",
  "message": "string"
}
```

### Tool: `calendar_event`
```json
{
  "title": "string",
  "datetime": "string (ISO8601 or natural description)"
}
```

### Tool: `chrome_browse`
```json
{
  "url": "string (Valid web address)"
}
```

### Tool: `file_manager`
```json
{
  "action": "string (enum: ['read', 'write', 'list'])",
  "path": "string",
  "content": "string (required for action='write')"
}
```

---

## 3. Error Handling and Resilience Standards
1. **Tool Invocation Failure:** If a tool call fails, the execution block returns a structured error payload to the TTS engine and logs it to SQLite without crashing the background daemon.
2. **LLM Formatting Faults:** If the model outputs unstructured conversational prose, the system routes the text directly to the TTS module.
3. **Audio Capture Faults:** If `termux-microphone-record` encounters audio resource lock conflicts, it executes an auto-reset (`termux-microphone-record -q`).
